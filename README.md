# Çay Felsefesi Makinesi

Bu proje, insanlığın en büyük sorularına cevap ararken çay demleme süresini temel alan, tamamen bilimsel ve hiçbir şekilde absürt olmayan bir sistemdir.

## Nasıl Çalışır?

1. Çayını demle.
2. Kaç dakika demlediğini söyle.
3. Makine sana hayatın anlamını, varolmanın acısını veya neden çayın soğuması gerektiğini açıklar.

## Özellikler

- %100 doğru felsefi öğütler
- Çay demleme süresine göre değişen derin içgörüler
- Hiçbir şekilde rastgele değil, tamamen deterministik (aslında rastgele)
- Türkçe konuşur, çünkü çay Türkçe sever

## Kurulum

```bash
python cay_felsefesi.py
```

Başka hiçbir şey yapmana gerek yok. Bu kadar.

## Uyarı

Bu makine çayını soğutmaz, sadece senin ruhunu soğutur.
